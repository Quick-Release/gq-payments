=== GQ Payments ===
Tags: payments, getquick
Requires at least: 7.0
Requires PHP: 8.4.1
Stable tag: 0.0.1
License: Proprietary

Payment provider integration scaffold for GETQUICK sites.

== Description ==

Version 0.0.1 provides the plugin bootstrap and lifecycle entry point.
Payment processing and provider integration are not implemented yet.

== Installation ==

1. Upload the release ZIP through Plugins > Add New > Upload Plugin.
2. Activate GQ Payments.

Composer/Bedrock installations can require getquick/gq-payments instead.
